# 风格系统：品牌声线与风格解析法

## 为什么需要风格系统

同一套内容，风格不同，传播力天差地别。爆文的传播动力是情绪，而情绪靠风格承载：节奏决定读感，声线决定记忆点。写作前先定风格，是专业创作者的默认动作。

**差异化黄金公式：基础赛道人设 + 差异化真实标签 = 独特人设。**
不追同质化——平台和个人博客都不需要第二个某某某，需要的是独一无二的你。

## 品牌风格卡片（示例：第一人称复盘者，可改写为自己的版本）

| 维度 | 定义 |
| --- | --- |
| 一句话定位 | 冷静的工程复盘者：诚实、具体、偶尔犀利，永远先给结论 |
| 人称 | 第一人称"我"复盘，第二人称"你"对话读者 |
| 句式 | 短句为主，长短交错；一段只讲一件事；先结论后解释 |
| 招牌动作 | ① 真实数据/踩坑现场开头；② 命令级 SOP；③ "说白了"式翻译复杂概念；④ 适度自嘲；⑤ 给出自己命名的小框架 |
| 情绪曲线 | 冷静铺陈 → 观点交锋（最犀利段落放 60% 处）→ 共鸣释放 → 收尾给确定感 |
| 金句策略 | 一篇至少一处可被单独引用的句子，放在小标题或段尾 |
| 禁项 | 假大空、正确的废话、夸张形容词堆砌（"非常""极其""震撼"）、无来源数据、标题党、居高临下的说教 |

### 语气示例

- 不写："本文将详细介绍如何配置 Hugo 博客。"（说明书腔）
- 要写："Hugo 配置的坑我踩了整整两个晚上，这篇文章能帮你省下来。"（复盘腔）

- 不写："Artalk 是一个非常好用的评论系统。"（空洞）
- 要写："选 Artalk 就一个原因：它的数据躺在我的服务器里，谁也拿不走。"（观点腔）

## 风格解析法（从对标文章提炼风格指纹）

遇到让你拍大腿的好文（不限领域），按 6 个维度拆解，生成风格卡片：

1. **用词偏好**：口语词还是书面语？技术黑话密度？有没有口头禅？
2. **句式长度**：平均句长？长短句怎么搭配？爱用问句还是陈述句？
3. **段落节奏**：段长控制？隔几段出现一个小高潮？
4. **情绪浓度**：全篇冷静还是全程煽情？情绪峰值出现在什么位置？
5. **观点表达方式**：先扬后抑、直接下结论、还是用故事绕进去？
6. **招牌句式**：有没有反复出现的句式骨架？（例："别人写 X，我偏要写 Y"）

产出一张风格卡片（如上表格式），之后套写时把卡片贴在上下文里。

### 风格解析示例（犀利复盘风）

> 人称：我/你。句长：以 15 字内短句为主，每 3~4 段来一个长句解释。节奏：小标题即观点，不绕弯。情绪：前 1/3 冷静，中间交锋，结尾释然。招牌句式："说白了，……""……，就这么简单。""我劝你……"。

## 应用流程

1. **解析**：对标 3~5 篇同领域爆文 → 提炼风格指纹 → 生成风格卡片。
2. **定卡**：本篇采用哪张卡片（默认用品牌风格卡片）。
3. **套写**：写作全程遵守卡片约束，写完逐段校对语气。
4. **沉淀**：写得顺的风格迭代进卡片库，形成自己的"风格资产"。

## 检查清单

- [ ] 本篇风格卡片已明确
- [ ] 开头第一段有钩子，语气不说明书腔
- [ ] 至少一处观点交锋段
- [ ] 至少一处可引用金句
- [ ] 全文无禁项（假大空/形容词堆砌/无来源数据）
- [ ] 作者个性可见——换个人名，读者能认出这不是别人写的
