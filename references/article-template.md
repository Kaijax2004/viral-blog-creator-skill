# 文章 Markdown 模板（双结构）

## 模板 A：搜索型（倒金字塔）

适合教程、部署、排错类选题，吃搜索 + AI 推荐流量。

```markdown
---
title: "标题：包含核心关键词 + 收益点"
description: "150 字以内，包含核心关键词，说明读完这篇文章能得到什么。"
slug: "url-keyword"
categories:
  - 分类
tags:
  - 标签1
  - 标签2
date: '2026-11-24T00:00:00+08:00'
lastmod: '2026-11-24T00:00:00+08:00'
license: false
readingTime: false
comments: true
image: cover.png
---

**TL;DR：** 一句话结论 + 适用人群 + 读完收益。

## 问题/背景

- 读者在什么场景下会遇到这个问题？
- 现有方案有什么痛点？
- 这篇文章要解决什么核心问题？

## 核心概念/原理

用 2~3 段解释关键概念。避免长篇大论，必要时用列表或表格。

```

- 说明验证方法

## 模板 B：传播型（爆文五段式）

适合观点、复盘、趋势、方法论类选题，吃完读和转发。

```markdown
---
title: "带冲突感或具体收益的标题"
description: "150 字以内，点明文章要回答的问题。"
slug: "url-keyword"
categories:
  - 分类
tags:
  - 标签1
  - 标签2
date: '2026-11-24T00:00:00+08:00'
lastmod: '2026-11-24T00:00:00+08:00'
license: false
readingTime: false
comments: true
image: cover.png
---

## 开头钩子（100 字以内）

三选一，3 秒抓住读者：
- 悬念："我把博客拆了重写了一遍，原因有点离谱。"
- 痛点："你是不是也收藏了 200 篇教程，一个都没动手？"
- 震撼数据："这篇文章带来的曝光，超过了我过去 3 年的总和。"

## 这个问题为什么重要

告诉读者为什么必须关心——不重要的东西没人愿意浪费时间。建立紧迫感：再不懂会错过什么、会踩什么坑。

## 背后的原因分析

深挖本质，给出超越表面现象的见解。这是全文的价值高地：
- 别人看到了什么 vs 你看到了什么
- 现象背后的规律是什么
- 至少给出 1 个"别人没有说过的"观点（信息增量）

## 解决方案 / 我的做法

具体、可操作、步骤清晰。不给大道理，给"今天就能做"的动作。
用小标题或编号分段，每段一个要点，配案例或数据。

## 你现在就可以做的事

明确的行动清单（3 条以内），促进实际行动。
最后留一个开放问题或邀请评论，引导互动。

---

> 作者：Kai Jax
> 博客：易安记 https://www.kaijax.cn
```

## 情绪曲线（传播型专用）

冷静铺陈 → 观点交锋（冲突感最强的段落放这里）→ 共鸣释放 → 收尾给出确定感。全文至少一处"写到人心坎里"的句子，一处可被引用的金句。

## 开头钩子库

| 类型 | 示例 |
| --- | --- |
| 悬念 | "我删掉了写了两年的博客，然后流量翻倍了。" |
| 痛点 | "配置第 5 次报错的时候，我开始怀疑人生。" |
| 震撼数据 | "这篇文章 3 天 17 万曝光，但我劝你别学我。" |
| 反常识 | "博客做得好的人，都不怎么懂 SEO。" |
| 身份代入 | "如果你也在用 Hugo + Artalk，这篇文章能救你一晚上。" |

## 模板使用说明

- description 必须包含核心关键词，且控制在 150 字以内。
- slug 用英文/拼音关键词，不要用无意义 ID。
- image 如果有封面图，必须和文章同目录或引用图床链接。
- date 和 lastmod 保持一致；更新文章时修改 lastmod。
- 两种结构可以混合：传播型开头 + 搜索型主体 + FAQ 收尾，是效果最好的折中方案。
- 发布前删除所有 [ ] 占位符和未完成的 TODO。
