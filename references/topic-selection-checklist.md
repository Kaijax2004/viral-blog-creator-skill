# 选题检查清单

## 0. 洞察与测试（动笔之前）

- [ ] **评论区洞察**：这个话题对应的用户（GitHub Issues、Stack Overflow、V2EX、知乎、竞品博客评论区）最近在焦虑什么？高频问题是什么？
- [ ] **选题库**：该选题已收录进个人选题库？（高频问题、共鸣话题、热点事件统一沉淀）
- [ ] **小范围测试 A**：竞品有没有人写过？有人写 = 有需求验证；没人写要警惕没有需求。
- [ ] **小范围测试 B**：评论区/社区有没有人在问这个问题？
- [ ] **小范围测试 C**（可选）：先发短内容/朋友圈试探反馈，反馈好再深度创作。
- [ ] **读者视角三问**：看完最大收获是什么？替读者省了什么？为什么现在就要看？答不上来就不写。

## 1. 需求验证

- [ ] 这个主题是否回答了一个真实存在的搜索问题？
- [ ] 目标读者是谁？他们现在在用什么方案？
- [ ] 这篇文章能帮助他们节省多少时间/避免什么坑？

## 2. 关键词验证

- [ ] 核心关键词是否有搜索量？（Google/Bing/百度）
- [ ] 搜索结果首页是否被大型网站垄断？
- [ ] 是否存在低竞争的长尾词可以切入？
- [ ] 关键词是否与博客定位（AI / 工作流 / 前端 / 个人成长）一致？

## 3. 时效性判断

- [ ] 是否有即将到来的节日/事件/版本发布可以借势？
- [ ] 是否可以在年底/年初/大型更新前提前 2~4 周布局？
- [ ] 这个话题是否具有长期价值，还是一次性热点？
- [ ] 热点来源：掘金/知乎热榜、V2EX、微博热搜、抖音/B站热榜、行业垂直社区。（敏感事件不人身攻击、不造谣，等官方通报再写，少用绝对化词）

## 4. 竞争优势（信息增量）

- [ ] 竞品内容有哪些不足？（太旧、太浅、没有案例、没有代码）
- [ ] 我有没有独特的经验、数据或视角？
- [ ] 我能不能提供竞品没有的代码、模板或 SOP？
- [ ] 我能不能多说一句"别人没有说的"？（信息增量：别人写"少吃多动"，你要写出"饿了可以吃水煮蛋"）

## 5. 可执行性

- [ ] 我是否愿意为这个主题投入至少 2 小时深度写作？
- [ ] 我是否能提供 1~2 个真实案例或截图？
- [ ] 这篇文章是否能在 30 天内写完并发布？

## 6. 评分表

| 维度 | 1 分 | 2 分 | 3 分 |
| --- | --- | --- | --- |
| 搜索需求 | 几乎没人搜 | 有一定搜索量 | 搜索量大且稳定 |
| 竞争程度 | 首页全是巨头 | 有 1~2 个机会 | 有机会进前 5 |
| 个人经验 | 没做过 | 做过但不深 | 深度踩过坑 |
| 内容独特性 | 网上很多 | 有一点新意 | 独家经验/SOP |
| 时效性 | 已经过时 | 长期有效 | 正好要爆发 |

**总分 ≥ 11 分才值得写。**
