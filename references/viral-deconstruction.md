# 爆文拆解三步法

> 用途：用户要求拆解、分析一篇爆文（或爆款视频脚本）时使用。拆解是学习者模式——拆别人的爆款，是为了找到自己的套路。

## 总原则

- **爆文不是灵感，是系统**。同领域的爆文，情绪节奏都差不多。拆满 5 篇，节奏就是你能复用的资产。
- **爆文 = 情绪共鸣 + 话题痛点**。拆解时始终问：这段文字调动了什么情绪？（焦虑/愤怒/认同/感动/好奇）
- **爆文观点多为大众共识 → 反向思考其对立面，往往能找到差异化新切入点。**

## 第一步：拆标题和开头

找 5 篇同领域近期爆文，只分析标题 + 前 100 字：

| 分析项 | 记录 |
| --- | --- |
| 标题用了哪套套路？ | 制造反差 / 数字具象 / 直击痛点 / 利益承诺 |
| 标题里的关键词是什么？ | 哪个词戳中了你？ |
| 开头是哪种钩子？ | 悬念 / 痛点 / 震撼数据 / 提问 / 反常识 |
| 共性结论 | 这些标题不是带冲突，就是有个词戳中了你 |

## 第二步：逐段标注

每读一段，标注其核心，摘录击中你的内容：

| 段落 | 核心类型 | 具体分析 |
| --- | --- | --- |
| 第 N 段 | 案例 / 观点 / 细节代入 | 用了什么案例？制造了哪种代入感？ |

记录引发共鸣的关键词句，并分析击中你的核心属于哪类：
- **情感认同**：说出了我压在心底的话
- **认知增量**：这个角度我从未想过
- **实用价值**：这条我现在就能用
- **谈资价值**：这个我可以转给朋友讨论

## 第三步：理全文逻辑

画出文章的"情绪曲线"：

1. **观点如何深化**：每段观点比上一段推进了什么？（现象 → 原因 → 本质 → 行动）
2. **情绪如何铺垫到爆发**：哪里是平静铺陈？哪里是交锋高峰？峰值出现在全文什么位置（通常在 55%~70%）？
3. **结尾如何处理**：金句如何升华？是否给出行动？是否留下思考空间或互动引导？

## 产出模板

拆解完成后，输出以下结构化结论：

```
【选题线索】这个话题为什么有需求？（对应哪个痛点/搜索问题）
【标题套路】四大套路中用了哪几个？关键词是什么？
【结构骨架】钩子类型 + 段落功能序列 + 情绪峰值位置
【风格指纹】6 维度简评（用词/句式/节奏/情绪浓度/观点方式/招牌句式）
【可复用资产】3 条以上可直接套用的句式/结构/角度
【差异化切入点】拆解观点的对立面，写出 1~2 个反向选题
```

## 应用闭环

拆解产出必须反哺创作：

1. 选题线索 → 录入选题库（系统一）
2. 标题套路 → 补充个人标题公式库（系统二）
3. 结构骨架 → 固化为个人模板（系统三）
4. 风格指纹 → 生成风格卡片（系统五）

拆 5 篇，写 1 篇，再拆 5 篇——这就是持续产出的闭环。
